##  Contenido y Ejercicios Desarrollados

La estructura del código fuente (`src`) de esta Fase 3 se organiza de la siguiente manera:

* **`APE_Clase3.Ejercicio1`**: 
  * Clases: `Autor`, `Libro` y `Main`.
  * Descripción: Implementación de objetos como atributos dentro de otra clase, mostrando la información detallada de libros y sus respectivos autores.

* **`APE_Clase3.Ejercicio2`**: 
  * Clases: `Rectangulo` y `Main`.
  * Descripción: Creación de la clase `Rectángulo` con atributos de base y altura, calculando área, perímetro, verificación de cuadrados y visualización de descripciones en consola. *(Realizado por el equipo)*

* **`APE_Clase3.Ejercicio3`**: 
  * Clases: `Producto`, `Venta` y `Main`.
  * Descripción: Envío de objetos como parámetros, validación de inventario (`reducirStock`) y procesamiento de transacciones comerciales.

* **`APE_Clase3.Ejercicio4`**: 
  * Clases: `Cuenta` y `Main`.
  * Descripción: Gestión de cuentas bancarias y método de transferencias entre objetos validando fondos disponibles.

* **`APE_Clase3.Ejercicio5`**: 
  * Clases: `Libro`, `Usuario`, `Prestamo` y `Main`.
  * Descripción: Colaboración entre múltiples clases para registrar y validar el préstamo de un libro ante intentos simultáneos de varios usuarios.
