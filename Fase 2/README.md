📚 Descripción del proyecto

En este avance de la APE 4 se desarrollaron ocho ejercicios prácticos utilizando el lenguaje de programación Java, enfocados en el aprendizaje y aplicación de métodos, parámetros, argumentos, tipos de retorno, validaciones y manejo de objetos.

🎯 Objetivos de aprendizaje

* Identificar y utilizar correctamente los tipos de retorno en Java.
* Crear métodos void y métodos que devuelvan valores.
* Diferenciar parámetros y argumentos.
* Comprender el funcionamiento del paso por valor.
* Implementar métodos con varios parámetros.
* Aplicar validaciones utilizando variables boolean.
* Trabajar con atributos y métodos de una clase.
* Instanciar objetos e invocar sus métodos desde el main.

🛠️ Herramientas utilizadas

* Lenguaje: Java
* Entorno de desarrollo: IDE compatible con Java
* Repositorio: GitHub

📌 Conclusión

Mediante el desarrollo de esta actividad se fortalecieron los conocimientos fundamentales de programación en Java, especialmente en la creación de métodos, el uso de parámetros y argumentos, las validaciones y la programación orientada a objetos.

Cada integrante participó en el desarrollo de los ejercicios asignados, contribuyendo al aprendizaje y cumplimiento de los objetivos de la APE 4.
